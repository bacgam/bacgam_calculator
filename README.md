# bacgam calculator

`index.html`을 더블 클릭해 브라우저에서 실행하세요. 별도 설치나 인터넷 연결이 필요 없습니다.

## GitHub 업로드

`bacgam-calculator.zip`의 압축을 풀고, 안에 있는 파일을 GitHub 저장소의 최상위 폴더에 업로드하세요. `index.html`, `styles.css`, `calculator.js`, `app.js`는 같은 폴더에 있어야 합니다.

## 사용법

1. **손절액 기준**(기본값) 또는 **전체시드 비율기준**을 선택하고 롱 또는 숏을 선택합니다.
2. 진입가와 손절가를 입력합니다. 손절액 기준에서는 손절액을 직접 입력하고, 전체시드 비율기준에서는 전체시드와 손절율(%)을 입력합니다. 손절율은 전체시드에서 감수할 손실의 비율이며, `전체시드 × 손절율 ÷ 100`으로 손절액을 계산합니다. 금액과 가격은 USDT 기준입니다. 기준을 바꿔도 각 입력값은 보존됩니다.
   입력창과 계산 결과의 숫자는 천 단위 쉼표로 표시됩니다. 입력 중 소수점과 자릿수는 유지되며, 계산에는 쉼표를 제외한 값을 사용합니다.
3. 손익비 1:1, 1:2, 1:3 중 하나를 선택하거나, 오른쪽 **커스텀 손익비** 박스를 클릭합니다. 팝업에서 마우스 휠로 1:0.5부터 1:10까지 0.5 단위로 조절하고 **적용**을 누릅니다. 방향키, 위아래 버튼, 터치 드래그로도 조절할 수 있습니다. 취소하거나 Escape로 닫으면 기존 손익비가 유지됩니다.
4. 포지션 진입금액과 수량, 손절가, 익절가, 손절액, 익절액을 확인합니다. 모든 입력과 선택은 즉시 반영됩니다.
5. 선택사항인 **Leverage**에 0보다 큰 배율을 소수점 첫째 자리까지 입력하면 **Margin**에 `포지션 진입금액 ÷ Leverage`가 표시됩니다. 비워 두거나 잘못 입력해도 기존 포지션 계산은 유지되며, Margin만 표시되지 않습니다. Margin은 보통 소수점 둘째 자리까지 표시하며, 0.01 미만의 금액에는 더 많은 자릿수를 표시합니다. 계산에는 반올림 전 값을 사용합니다.

롱은 손절가가 진입가보다 낮아야 하며, 숏은 손절가가 진입가보다 높아야 합니다. 숏의 익절가가 0 이하인 설정에는 결과 대신 안내를 표시합니다.

## 계산 기준

- 전체시드 비율기준의 손절액 = 전체시드 × 손절율 ÷ 100 (0% 초과, 100% 이하)
- 진입 수량 = 손절액 ÷ |진입가 − 손절가|
- 포지션 진입금액 = 진입 수량 × 진입가
- Margin = 포지션 진입금액 ÷ Leverage (선택사항)
- 익절액 = 손절액 × 선택한 손익비 배수
- 롱 익절가 = 진입가 + |진입가 − 손절가| × 손익비 배수
- 숏 익절가 = 진입가 − |진입가 − 손절가| × 손익비 배수

예: 진입가 65,000, 손절가 64,000, 손절액 100, 롱, 손익비 1:2 → 진입 수량 0.1, 진입금액 6,500 USDT, 익절가 67,000, 익절액 200 USDT.

가격 × 수량으로 손익이 결정되는 선형 상품 기준입니다. 수수료, 슬리피지, 펀딩비는 제외됩니다. 진입금액은 포지션 총액이며 레버리지를 반영한 필요 증거금이 아닙니다. 수량과 금액의 표시는 최대 소수점 8자리로 반올림하지만 계산에는 원래 정밀도를 사용합니다.
